<build_notes_decision>
**Decision: yes, but narrowly — and not a copy of §9.**

`docs/BUILD-NOTES.md` §3 carries the **binding citation rule**: an Evidence cell "that does not name
at least one of the five ToolKit JSON files, one of the prose reference docs, or one golden-shortcut
XML filename **is not acceptable**." As written, that rule admits no simulator observation at all — so
a future agent who runs a simulator trial has no legal way to cite it, and the finding either gets
dropped or gets laundered into a file-level citation it did not come from. That is a functional gap
in BUILD-NOTES, not a redundancy with CLAUDE.md.

fact — no device UDID, no app count, no runtime version, no tool inventory — and points at CLAUDE.md
§9 as the single home for those. Nothing is duplicated, so nothing can drift.
