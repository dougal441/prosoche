## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| source XML → signed `.shortcut` | The signed AEA1 container is what a phone actually runs. A container that does not match the source it claims is the one tampering surface this project genuinely has. |
| signed artifact → the developer's iPhone | The only place the product's behaviour becomes real. Everything upstream is structural. |
| measured fact → written record | A structurally green build recorded as device evidence corrupts every later decision that reads the record. |
