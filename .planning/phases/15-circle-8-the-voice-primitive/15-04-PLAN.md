## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| user consent → the speech action | The only boundary in the product where a stored user answer decides whether the device produces output the user did not initiate. |
| the Shortcut → the device's audio output | The outward-facing effect. There is no network, no credential, no external service. |
| Config sequence table → emitted dispatch branches | A name-to-behaviour binding that no validator, catalog or decrypt can check, because every one of them sees a well-formed conditional whatever it contains. |
