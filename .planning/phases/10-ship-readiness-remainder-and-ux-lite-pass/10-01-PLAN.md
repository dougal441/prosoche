now, but nothing is shown at all: no notification, no menu, no primitive. Raise every profile's

(notification, Leaving/Continue menu, Knock alert). A user buried in pop-ups deletes the
Shortcut, which is the canonical strategy's own stated key failure. Going quiet by default is
the single highest-leverage UX change available before ship.

makes that property structural, and a canonical-strategy amendment recording the band.

## Circle gains the value 0 - identity change record

**Noun now primary:** `Circle`. Its domain moves from **1..9** to **0..9**. Today
`open_pipeline()` seeds `Circle Next` at 1 and the threshold scan only ever raises it, so every
consumer may currently assume "a Circle always means an intervention fires". After this plan,
`circle == 0` means "state accumulated, nothing was shown".

**Decision: `promote`.** Circle 0 becomes a first-class value of the existing `circle` field
rather than a new parallel `silent` flag. Rationale: the threshold scan already computes the
value, `set_value("circle", ...)` already persists it, and every consumer already reads it - a
second boolean would create two sources of truth for "did anything happen" and would have to be
kept consistent by hand at every write site. No `schema_version` bump: `circle` is an existing
key whose value range widens, and a widened range needs no migration.
