<objective>
Stop the Control Room Note opening when nobody asked for it, and give the manual menu the two
things a confused first-run user needs: a prompt that explains itself, and a Setup Check item that
answers "did my automations actually get wired up?".

Purpose: `is.workflow.actions.shownote` sits at depth 0 in the MANUAL arm, outside every
conditional, so all nine menu items end by launching the Notes app - and the one item that should
do it, Open Control Room, is a bare no-op relying on that unconditional tail. Meanwhile a first-run
user meets a nine-item menu titled only with the product name before they have ever seen the Note
that explains what any of it is.

Output: a Dumb artifact whose Note opens only on request, whose manual menu explains itself, and
whose tenth menu item reports Personal Automation status from state PROSOCHE already records.
</objective>
