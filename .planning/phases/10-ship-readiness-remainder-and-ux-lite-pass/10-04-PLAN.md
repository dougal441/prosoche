red this phase because the Sentient fork is stale. It is not stale: commit `c6d8737` regenerated and

green invariant into a red one, which is the opposite of the brief's intent. **Decision: rebuild
Sentient in this plan and keep the check green.** `tools/build_sentient.py` needs no edit, exactly as
the scope correction states, because the cancelled cut leaves all ten of its imported

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Repository source -> signed `.shortcut` artifact | Signing is the point at which what was built becomes what ships. Everything between the last check and the signature is unverified unless the artifact is decrypted |
| Signed artifact -> the user's Shortcuts library | Import is by display name; a wrong name creates a second library entry the automations do not reference |
| `MANIFEST.md` -> the artifacts it describes | The only human-readable claim about what shipped. A stale row is a false provenance claim |
