## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| iOS device state → shortcut run | `Get Device Details` returns an external reading that may be absent, empty, or a type the plist cannot see. Untrusted input crosses here. |
| `state.json` on disk → shortcut run | State persists across runs and across crashes; a run may find it absent, stale, or holding a sentinel. |
| generator (build time) → signed artifact (run time) | Ordering decisions made here become unfixable at run time — Shortcuts has no try/catch, so safety is achieved by ordering, not detection. |
