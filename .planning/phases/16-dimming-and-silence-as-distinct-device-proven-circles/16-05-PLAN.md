<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| signed artifact → the user's device | Once imported, the artifact changes the user's display and volume with no runtime supervision. |
| manifest row → a reader identifying a build already on a device | A stale or hand-edited row makes it impossible to tell which build a device is running. |
| measured device state → the recorded verdict | The gap between what was measured and what gets written down is where a fabricated result would enter. |
| display name → the user's Personal Automations | The automations bind by exact display name and the filename is the sole carrier of that name. |
