## Decision legend (source: `01-CONTEXT.md`)

- **D-03** — Sentient uses the Apple On-Device model only. Never Private Cloud Compute, never ChatGPT, never a web API.
- **D-06** — PROSOCHĒ is bypassable and must never claim otherwise.
- **D-07** — The "do not fabricate" protocol: safest fallback, record the deviation, keep the Shortcut runnable. UNVERIFIED is a correct outcome; an invented identifier is a defect.
- **D-11** — Blocker 4, the `Use Model` On-Device literal: the exact plist key or enum that pins On-Device is unknown. Attempt recovery from the ToolKit enum snapshots first. If it cannot be recovered from the local toolchain, record it as an explicit user action item (select On-Device in Shortcuts.app, export the unsigned XML, read the literal back) and state plainly how Phase 8 is gated on it. Do NOT guess an enum string.
