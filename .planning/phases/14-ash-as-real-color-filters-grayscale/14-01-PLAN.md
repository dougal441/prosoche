<objective>
Make Ash a real Color Filters grayscale toggle, wired end to end into the existing
capture-and-restore machine, and prove it structurally on both forks.

phase will modify — the action emitter, the primitive, the restore expansion, the persisted
state shape, and the two build guards that make the slice provable rather than merely
present — and it carries a real end-to-end verify. Task 2 arms the remaining guard and
proves the slice under a negative control's shadow.

identifier, both parameter values and the elision rule. Authoring the action is the smallest
part of the work. The work is everything it must be wired into.

Purpose: CIRC-02's audited visual-salience reduction is the only primitive in the product
still not implemented as designed, and it carries the strongest research support in the
canonical strategy. SAFE-05's requirement text has promised colour restore since Phase 1 and
the build has never delivered it.

Output: both forks emit the AX action at fifteen sites each, the bootstrap template seeds a
third snapshot group, and two build guards can see grayscale for the first time.
