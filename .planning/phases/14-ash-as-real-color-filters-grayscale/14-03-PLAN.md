<objective>
Tell the user, then ship it.

The build now does something to the user's phone that the user has no way to detect and no way
to consent to. No read-back intent exists for any accessibility setting, so the rule against
overriding a pre-existing accessibility state **cannot be satisfied by detection**. The remedy is
a kill switch plus a plain-language disclosure, and the disclosure is a **deliverable**, not a
nicety.

One file meanwhile asserts two contradictory things about this primitive at once — the residual
documentation defect AUDIT-02 names — and the ROADMAP still describes the snapshot design the
scope reset retired. Both get corrected here, alongside the ship work: rebuild, re-sign, refresh
the manifest, author the device instrument, retire the backlog phase.

Purpose: AUDIT-02 closes. SAFE-02's genuine threat surface in this phase is clobbering a user's
assistive configuration, and disclosure is the only mitigation available. SAFE-05's promise
becomes a promise the artifact can keep.

Output: a Note that tells the truth, a record that stops contradicting itself, two signed forks
that match their manifest rows, and a device instrument that is honest about having never run.
</objective>
