<objective>
Ship what the phase built, instrument what it cannot prove, and close the backlog entry it
supersedes.

**Everything this phase ships is structurally proven and behaviourally unproven.** The toggle has
never run on hardware. The restore has never been observed closing. No simulator observation was
promoted above unverified for the grayscale behaviour itself. That is the same position the
previous environmental phase shipped in, and the same discipline applies: the record says so on
its front, and the instrument is authored whether or not a device is reachable today.

**Routing grayscale through the one existing restore expansion has a payoff that is collected
here.** All three environmental primitives now restore through the same code path from the same
four call sites, so **one device sitting can prove all three**. The instrument is therefore
designed to be run alongside the phase-16 instrument's twelve outstanding tests rather than as a
separate session, and it carries a batching table saying which tests share setup.

**The single most valuable observation in this phase is not "does the screen go grey".** It is:
force-quit mid-intervention, then run Emergency Restore, and confirm colour, brightness and
volume all come back. That one test exercises the persist-before-apply ordering, the ownership
marker's survival across a process death, and the three-group restore expansion, in a single
sequence — and none of those has ever been observed on a phone.

Purpose: the project's own rule is that a valid draft without a signed artifact is not a useful
stopping point, and that a probe's result is recorded rather than consumed. This plan discharges
both, and closes the backlog phase whose one open step this phase is.

Output: two re-signed forks with a refreshed manifest, a cold-runnable device instrument, a
recording section, and one fewer open backlog entry.
</objective>
