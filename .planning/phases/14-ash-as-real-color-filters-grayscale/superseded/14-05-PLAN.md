<objective>
Make the record honest and the change disclosed.

**The build now does something to the user's phone that the user has no way to detect and no
way to consent to.** There is no read-back for any accessibility setting across all thirty-five
intents in the framework, so the rule against overriding a pre-existing accessibility state
cannot be satisfied by detection. The remedy is an opt-out flag plus a plain-language disclosure
— a settled user decision from 2026-08-17 — and the disclosure is a **deliverable**, not a
nicety. A user who runs Color Filters deliberately for colour-blindness, migraine or low vision
must be able to find out that PROSOCHĒ will turn it on and off, and be able to stop it.

**And one file currently asserts two contradictory things about Ash at once**, which is the
residual documentation defect AUDIT-02 names. The pattern map found two stale sites in it. There
are **four** — re-measured during planning — and the fourth is a claim about a checker assertion
that plan 14-03 has already inverted, which means the file is now stating something demonstrably
false about the repository it describes.

Purpose: AUDIT-02 closes on this file. SAFE-02's genuine threat surface in this phase is
clobbering a user's assistive configuration, and disclosure is the only mitigation available.

Output: a Control Room Note that tells the truth, a config mirror that stops contradicting
itself, and a capability record that says the decision is now implemented.
</objective>
