<objective>
Fix the confirmed root cause of G-04-1 (session duration always records as 0) and G-04-3 (the
session race never switches — CLOSE is a permanent no-op), then sweep the same defect class
(an unfinished two-step `WFConditionalActionString` wiring idiom) across every other site in
`tools/build_state_engine.py` where it was left incomplete, and add a build-time guard so it
cannot ship silently again.

Purpose: `close_pipeline()`'s session-ownership conditional is the single gate for the only
code path in the entire artifact that appends to `recent_sessions`, clears `active_session`,
restores settings, and saves `state.json`. Because its comparator was left as a bare,
un-enveloped placeholder character instead of being wired to the captured session ID, that
gate can never open — CLOSE silently no-ops on every real invocation. Two device-run UAT
tests (`.planning/phases/04-close-pipeline-session-race/04-UAT.md` tests 1 and 3) both traced
to this one line. The same unfinished idiom recurs at ~9 other sites across
`enabled_exits()`, `select_exit()`, `record_exit_and_route()`, and `open_pipeline()`,
confirmed by direct plist decode in both debug sessions
(`.planning/debug/G-04-1-close-duration-zero.md`, `.planning/debug/G-04-3-session-race-not-switching.md`).
Per this project's own debugging discipline ("fix whole classes, never site-by-site"), this
plan closes every instance in one pass and adds the missing build-time recurrence guard.

Output: A corrected `tools/build_state_engine.py`, a regenerated and re-signed
`PROSOCHĒ — Nine Circles — Dumb.shortcut`, and a new `verify_conditional_action_string()`
build guard. On-device re-verification of UAT tests 1, 3, and 6 happens in a later
`/gsd-verify-work` pass, not in this plan.
</objective>
