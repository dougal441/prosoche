## Phase goal (verbatim from ROADMAP.md)

> A user can import the Shortcut, run it manually for the first time, and get a working state.json plus a fully instructive Control Room Note — and every subsequent invocation routes correctly and never corrupts or duplicates that foundation.

setup plus a Note that tells me exactly what to do next, **so that** I can finish installing a
system that interrupts my automatic app-opening without having to read any documentation.

## Decision legend (source: `.planning/phases/02-routing-bootstrap-control-room/02-CONTEXT.md`)

D-14 onward index the locked decisions in Phase 2's CONTEXT.md, continuing Phase 1's D-01..D-13.

- **D-14** — Monolithic graph. One shortcut per fork, no internal `Run Shortcut` hops.
- **D-15** — Nested `If`/`Otherwise` only. `Otherwise If` is macOS-27+ and unusable at the iOS 26 target.
- **D-16** — Three invocation modes off Shortcut Input: absent/empty → MANUAL, `OPEN`, `CLOSE`. Unrecognised input must fail safe.
- **D-17** — Timestamps are integer Unix epoch seconds (UTC); `behavioural_day` is an ISO date-key string; use the 1970-anchor → `Get Time Between Dates` pattern.
- **D-18** — One JSON state file, one Apple Note. No CSV, no second machine store.
- **D-19** — State is bounded and versioned: rolling windows for sessions, contracts and per-exit aggregates; no unbounded arrays.
- **D-20** — PROSOCHĒ is bypassable and the Note must say so plainly.
- **D-21** — Hazard: the camelCase content key on Note creation. The short form passes the validator and yields an empty Control Room Note body at runtime.
- **D-22** — Hazard: display strings must not use the data-flow token serialization; they render blank at runtime while the plist still validates.
- **D-23** — Hazard: `GroupingIdentifier` collisions in nested blocks.
- **D-24** — Hazard: dictionary coercion. Booleans read back as `1`/`0`, `null` reads back as empty, a nested read on a null parent breaks, and any value destined for an `If` must pass through a `Text` action first.
- **D-25** — Hazard: the validator can pass a broken shortcut. Validation is necessary, not sufficient — reason through the variable wiring manually.
- **D-26** — Source file convention: author at `src/PROSOCHE-Dumb.xml`; keep it validating at every commit.

**Reversibility gates are off for this run.** Task 1 is rated `one-way` because it fixes the plist
