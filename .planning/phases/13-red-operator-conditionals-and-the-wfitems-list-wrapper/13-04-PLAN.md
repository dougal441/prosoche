**The definition of done includes signing.** A valid XML draft without a signed `.shortcut` is
not a useful stopping point. The signed basenames must be exactly the two canonical display
names — `PROSOCHĒ — Nine Circles — Core.shortcut` and `PROSOCHĒ — Nine Circles — Aware.shortcut`.
`.claude/CLAUDE.md` § 8's filename-discipline rule is unchanged but its example names are

DIST-04, and signing to the old names would fail that checker. The *source* filenames
deliberately remain `src/PROSOCHE-Dumb.xml` and `src/PROSOCHE-Sentient.xml`.

**Signed-name discipline is load-bearing, not cosmetic.** Measured by decryption in an earlier
phase: a signed `.shortcut` carries no display name internally — the AEA1 auth data holds only
the certificate chain and the signer strips `WFWorkflowName`. The filename is the sole carrier,
so a suffixed file imports as a second, differently-named library entry that the user's two
Personal Automations do not reference — a silently dead install.

**The device question is planned with its blocked branch explicit.** Phase 10's device UAT was
blocked, all ten tests were left blank, and DIST-03 is still open; Phase 12 followed the same
posture. That is this project's recorded stance and it is the right one: a fabricated pass is
worse than a blank. `13-UAT.md` must therefore be runnable cold at any later date, and the
reachability probe must produce a recorded verdict either way.

**Binding constraints.** D-01 (build provenance ancestor check before either generator),
D-02 (gate A mandatory and clean; gate B advisory, standalone, never `&&`-chained) and
D-03 (never fabricate a shape, and never fabricate an observation) apply unchanged from
`13-01-PLAN.md` `<objective>`. D-04 is discharged here: this is the plan that makes
