<objective>
Convert every emitted `active_session` gate, write and clear from **container semantics** to
**leaf semantics**, then empty `KNOWN_SENTINEL_EXISTENCE_GATES` so the registry honestly
reads zero remaining state-shape gaps.

Measured blast radius (`12-RESEARCH.md`, produced by re-running `verify_sentinel_gates()`'s
own two rules with the deferral emptied): **34 emitted offenders** — 15 condition-100
existence gates over a sentinel-written `active_session`, and 19 dotted reads hanging
beneath it. Those 34 emitted actions come from only **six generator functions**, because
`persist_contract()` renders 11× via `primitive_dispatch()` and `record_exit_and_route()`
renders 2×. This is the phase's governing rule made concrete: **fix whole classes, never
site-by-site.** Every defect in this project's debug history was systematic — 147, 367, 25,
20 and 8 sites — and bisection only ever reveals the earliest remaining one, so incremental
fixing costs one device round trip per site.

Plan 12-02 made the container a permanent seeded invariant. That changes the *correct*
shape of every gate: an existence test over a key that always exists is dead code, and the
condition-4 ownership compare that already sits inside each of those gates reads false for
the sentinel on its own. So four of the six sites lose a read and a conditional outright,
one gains a leaf gate where it previously had an existence gate, and one — `route_exit()`'s
Create branch — needs **no change at all**, because a bare `.id` dotted read followed by a
condition-4 ownership compare is already the target shape once the container is guaranteed.

Purpose: EXIT-01 and EXIT-02 both route through `record_exit_and_route()`'s gate; SESS-07
and SAFE-01 both depend on `restore_managed_settings()` being reachable through
`close_pipeline()`'s gates. Output: a plist with zero sentinel-existence offenders and an
empty exemption registry.

Binding constraints D-01..D-04 as stated in `12-01-PLAN.md` `<objective>` apply unchanged.
</objective>

nothing — one read, one conditional, exactly the economy `complete_pending_exit()`
demonstrates. Adding a condition-5 gate *as well* would be two conditionals where one
suffices, which is the alternative `12-RESEARCH.md` explicitly rejects.
