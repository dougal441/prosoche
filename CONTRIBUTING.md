# Contributing

PROSOCHĒ is a small project, and this page is honest about what can and cannot be merged.

## The shortcut

The shortcut is generated by a private tool. `source/PROSOCHE.xml` is a published record of exactly what was signed, so a pull request that changes anything under `source/` cannot be merged. The next version comes from the generator, not from edits to that file.

## Documentation

Fixes to the documentation are welcome as pull requests. That includes:

- wording that is unclear
- steps that no longer match what the screen shows
- screenshots from other iOS versions, with nothing personal in them
